\# 🖥️ Arduino PC Monitor Bridge



Автоматизированная система мониторинга аппаратных ресурсов ПК (RTX 4070 Ti / i7-12700K) с выводом основных метрик на LCD-дисплей 20x4 через плату Arduino Nano/Uno.



Все вычисления, парсинг температур и логика обработки данных работают на стороны Python (в виде фоновой службы в трее), благодаря чему прошивка Arduino остается максимальна легкой и надежной.



\---



\## ⚡ Особенности



\* \*\*Точные показатели CPU:\*\* Прямой парсинг реальной температуры `CPU Package` через локальный сервер \*\*LibreHardwareMonitor\*\*.

\* \*\*Прямой доступ к GPU:\*\* Забор показателей температуры, загрузки и видеопамяти \*\*RTX 4070 Ti\*\* через библиотеку `pystray`/`pynvml` (NVIDIA Management Library).

\* \*\*Фоновый режим и трей:\*\* Приложение запускается без окна консоли (`pythonw.exe`), сразу сворачивается в системный трей и не отвлекает при работе.

\* \*\*Защита от перелива дисплея:\*\* Автоматическая коррекция строк при 100% загрузке (подавление `%`), предохраняющая экран от артефактов и наложения текста.

\* \*\*Автозапуск с Windows:\*\* Настройка запуска вместе с системой прямо из GUI приложения в один клик.



\---



\## 📂 Структура проекта



\* `Monitor.pyw` — Python-служба для сбора метрик ПК, управления треем и отправки данных по COM-порту.

\* `PCdisplay\_2026\_ApodeZ/` — Папка с готовым скетчем C++ для прошивки Arduino Nano / Uno.

\* `.gitignore` — Исключения системных и временных файлов для Git.

\## 🛠️ Требования и установка



\### 1. Аппаратная часть

\* \*\*Arduino Nano / Uno\*\* (подключение по USB).

\* \*\*LCD Дисплей 20x4\*\* с модулем I2C (адрес `0x27`).



\### 2. Программная часть ПК

1\. Установленный \*\*Python 3.10+\*\*.

2\. Скачанный и запущенный \*\*\[LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)\*\*.

&#x20;  \* \*Важно:\* LibreHardwareMonitor должен быть запущен \*\*от имени администратора\*\*.

&#x20;  \* В настройках программы включите веб-сервер: `Options` -> `Remote Server` -> `Run` (порт по умолчанию `8085`).



\### 3. Зависимости Python
