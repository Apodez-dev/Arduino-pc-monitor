# 🖥️ Arduino PC Monitor Bridge

Автоматизированная система мониторинга аппаратных ресурсов ПК (RTX 4070 Ti / i7-12700K) с выводом основных метрик на LCD-дисплей 20x4 через плату Arduino Nano/Uno.

Все вычисления, парсинг температур и логика обработки данных работают на стороне Python (в виде фоновой службы в трее), благодаря чему прошивка Arduino остается максимально легкой и надежной.

---

## ⚡ Особенности

* **Точные показатели CPU:** Прямой парсинг реальной температуры `CPU Package` через локальный сервер **LibreHardwareMonitor**.
* **Прямой доступ к GPU:** Забор показателей температуры, загрузки и видеопамяти **RTX 4070 Ti** через библиотеку `pynvml` (NVIDIA Management Library).
* **Фоновый режим и трей:** Приложение запускается через `pythonw.exe` без черного окна консоли, сворачивается в системный трей с помощью `pystray` и `Pillow`, и работает полностью в фоне.
* **Защита от перелива дисплея:** Автоматическая коррекция строк при 100% загрузке (подавление `%`), предохраняющая экран от артефактов и наложения текста.
* **Автозапуск с Windows:** Настройка запуска вместе с системой прямо из GUI приложения в один клик через реестр Windows.

---

## 📂 Структура проекта

* `Monitor.pyw` — Python-служба для сбора метрик ПК, управления треем и отправки данных по COM-порту.
* `PCdisplay_2026_ApodeZ/` — Папка с готовым скетчем C++ для прошивки Arduino Nano / Uno.
* `.gitignore` — Исключения системных и временных файлов для Git.

## 🛠️ Требования и установка

### 1. Аппаратная часть
* **Arduino Nano / Uno** (подключение по USB).
* **LCD Дисплей 20x4** с модулем I2C (адрес `0x27`).

### 2. Программная часть ПК
1. Установленный **Python 3.10+** (для фоновой работы используйте `pythonw.exe`).
2. Скачанный и запущенный **[LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)**.
   * *Важно:* LibreHardwareMonitor должен быть запущен **от имени администратора**.
   * В настройках программы включите веб-сервер: `Options` -> `Remote Server` -> `Run` (порт по умолчанию `8085`).

### 3. Зависимости Python
Установите все необходимые библиотеки для мониторинга железа, работы с NVIDIA и иконкой в трее одной командой:

```bash
pip install psutil pyserial pynvml pystray pillow
